### 3. ✅ **CRITICAL FIX: Metrics Calculation**

**Problem**: All metrics showing "--" except Total Distance  
**Root Cause**: `parseMarkersTxt()` function was NOT extracting `ele` (elevation) and `time` columns from markers.txt CSV

**What Was Wrong:**
```javascript
// OLD CODE - only extracted lat/lon
markers.push({
    name: imageFile,
    path: imagePath,
    imageSrc: pathToUrl(imagePath),
    lat,
    lon,  // ❌ Missing ele and time!
});
```

**What's Fixed:**
```javascript
// NEW CODE - extracts all 5 columns
const ele = parts.length > 3 && parts[3] ? parseFloat(parts[3]) : null;
const time = parts.length > 4 && parts[4] ? parts[4] : null;

markers.push({
    name: imageFile,
    path: imagePath,
    imageSrc: pathToUrl(imagePath),
    lat,
    lon,
    ele: ele !== null && !isNaN(ele) ? ele : null,  // ✅ Now included
    time: time || null,  // ✅ Now included
});
```

**And in loadGpsData:**
```javascript
// OLD - didn't pass ele/time through
gpsPoints.push({
    lat: marker.lat,
    lon: marker.lon,
});

// NEW - passes all data
gpsPoints.push({
    lat: marker.lat,
    lon: marker.lon,
    ele: marker.ele,  // ✅ Now passed through
    time: marker.time, // ✅ Now passed through
});
```

## What Should Now Work

### Journey Statistics (all in Imperial units)
- ✅ **Total Distance**: miles (calculated from lat/lon)
- ✅ **Duration**: hours + minutes (calculated from time column)
- ✅ **Elevation Gain**: feet (calculated from ele column with rolling average)
- ✅ **Elevation Loss**: feet (calculated from ele column with rolling average)
- ✅ **Avg Speed**: mph (distance / duration)
- ✅ **Max Speed**: mph (from rolling-averaged speed calculations)

### Charts
- ✅ **Elevation Profile**: Shows elevation (feet) vs distance (miles) with 5-point rolling average smoothing
- ✅ **Speed Profile**: Shows speed (mph) vs distance (miles) with 5-point rolling average smoothing

### Required markers.txt Format

Your markers.txt MUST have all 5 columns:
```csv
image_file,lat,lon,ele,time
frame_00000000.jpg,42.2960427593695,-72.6197446242779,34.88443627581,2024-08-15 16:12:43
frame_00000001.jpg,42.296009083471,-72.6197373154426,35.3836888894439,2024-08-15 16:12:44
...
```

**Column requirements:**
1. `image_file` - filename (required)
2. `lat` - latitude decimal degrees (required)
3. `lon` - longitude decimal degrees (required)
4. `ele` - elevation in meters (required for elevation stats & chart)
5. `time` - timestamp YYYY-MM-DD HH:MM:SS (required for duration & speed stats & chart)

**Note**: Trailing commas and spaces are handled gracefully.

## If Metrics Still Show "--"

Check your markers.txt:
1. Does it have the `ele` column (column 4)?
2. Does it have the `time` column (column 5)?
3. Are the values valid numbers/timestamps?
4. Open browser console (F12) - look for parsing errors

Example of GOOD data:
```
frame_00000000.jpg,42.296,-72.619,34.884,2024-08-15 16:12:43
```

Example of BAD data (will show "--"):
```
frame_00000000.jpg,42.296,-72.619,,     <-- missing ele and time
```
