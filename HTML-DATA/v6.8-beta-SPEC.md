### 2. Rolling Average Smoothing
**Purpose:** Smooth out noisy GPS data for better visualization

**Implementation:**
```javascript
const ROLLING_AVG_WINDOW = 5; // Number of points to average

function rollingAvg(arr, window) {
    const result = [];
    for (let i = 0; i < arr.length; i++) {
        let sum = 0, count = 0;
        const start = Math.max(0, i - Math.floor(window/2));
        const end = Math.min(arr.length-1, i + Math.floor(window/2));
        for (let j = start; j <= end; j++) {
            if (arr[j] != null && Number.isFinite(arr[j])) {
                sum += arr[j];
                count++;
            }
        }
        result.push(count > 0 ? sum / count : null);
    }
    return result;
}
```

**Apply to:**
- Elevation data (smooths terrain profile)
- Speed data (removes GPS jitter)

### 3. Journey Statistics Dashboard

**Stats to Display:**
- Total Distance (mi or km)
- Duration (hours + minutes)
- Elevation Gain (ft or m)
- Elevation Loss (ft or m)
- Average Speed (mph or km/h)
- Max Speed (mph or km/h)
- Min/Max Elevation (ft or m)
- Start/End Times (from markers.txt)

**Calculation:**
1. Parse markers.txt: `image_file,lat,lon,ele,time`
2. Calculate distances using Haversine formula
3. Apply rolling average to elevation and speed arrays
4. Calculate cumulative stats from smoothed data
5. Convert to imperial units for display

### 7. JavaScript Functions Needed

1. **Unit Conversion:**
   - `km2miles(km)` - kilometers to miles
   - `m2feet(m)` - meters to feet
   - `kmh2mph(kmh)` - km/h to mph

2. **Data Smoothing:**
   - `rollingAvg(array, window)` - rolling average calculator

3. **Stats Calculation:**
   - `calcJourneyStats(points)` - comprehensive stats from GPS points
   - Returns: distances, elevations (raw & smoothed), speeds (raw & smoothed), times, totals

4. **Chart Creation:**
   - `createElevationChart(stats)` - renders elevation profile
   - `createSpeedChart(stats)` - renders speed profile  

5. **Display Updates:**
   - `updateJourneyStats(stats, source)` - populates stats cards
   - `formatDistance(km)` - formats with correct units
   - `formatElevation(m)` - formats with correct units
   - `formatSpeed(kmh)` - formats with correct units

### 8. Data Flow

```
1. Load dataset → Parse markers.txt
2. Extract: lat, lon, ele, time for each image
3. Calculate:
   - Haversine distances between consecutive points
   - Cumulative distance array
   - Speed from time deltas: distance / time_diff
   - Elevation changes
4. Apply rolling average:
   - Smooth elevation array (window=5)
   - Smooth speed array (window=5)
5. Calculate stats:
   - Total distance, duration
   - Elevation gain/loss from smoothed data
   - Avg/max speed from smoothed data
6. Convert to imperial units:
   - km → miles
   - meters → feet
   - km/h → mph
7. Render:
   - Stats cards with imperial values
   - Elevation chart (x=miles, y=feet)
   - Speed chart (x=miles, y=mph)
```

### 10. Benefits of Rolling Average

**Without smoothing:**
- GPS elevation jumps erratically (±5-10m)
- Speed spikes from GPS jitter
- Charts look noisy and unprofessional

**With smoothing (window=5):**
- Smooth elevation profile shows actual terrain
- Realistic speed profile without spikes
- Professional-looking visualizations
- Easier to identify trends
