## How It Works

### Data Flow
```
1. Load dataset → Read markers.txt (or EXIF fallback)
2. Parse GPS data: lat, lon, ele, time
3. Calculate distances (Haversine formula)
4. Calculate speeds from time deltas
5. Apply 5-point rolling average to elevation & speed
6. Calculate statistics from smoothed data
7. Convert to imperial units
8. Render charts and stats
```

### markers.txt Format
```csv
image_file,lat,lon,ele,time
frame_00000000.jpg,42.2960427593695,-72.6197446242779,34.88443627581,2024-08-15 16:12:43
frame_00000001.jpg,42.296009083471,-72.6197373154426,35.3836888894439,2024-08-15 16:12:44
...
```

**Required columns:**
- `image_file`: Frame filename (required)
- `lat`: Latitude in decimal degrees (required)
- `lon`: Longitude in decimal degrees (required)
- `ele`: Elevation in meters (required for elevation chart & stats)
- `time`: Timestamp YYYY-MM-DD HH:MM:SS (required for speed chart & stats)

## Technical Details

### Rolling Average Algorithm
Smooths noisy GPS data by averaging each point with its neighbors:
- Window = 5 points
- Each point averaged with ±2 neighbors
- Handles missing data gracefully
- Preserves overall trends while removing noise

### Unit Conversions
```javascript
kilometers → miles:  × 0.621371
meters → feet:       × 3.28084
km/h → mph:          × 0.621371
```

## Configuration

Edit these constants in the JavaScript section:

```javascript
// Unit system: 'imperial' or 'metric'
let UNIT_SYSTEM = 'imperial';

// Rolling average window size
const ROLLING_AVG_WINDOW = 5;

// Preloading settings
const PRELOAD_FORWARD_COUNT = 15;

// Auto-play speed range
const AUTOPLAY_MIN_IMAGES_PER_SECOND = 1;
const AUTOPLAY_MAX_IMAGES_PER_SECOND = 12;
```

## Known Limitations

1. **Elevation & Speed charts**: Require markers.txt with `ele` and `time` columns
2. **EXIF fallback**: Very slow for large datasets (downloads all images)
3. **Rolling average**: First/last few points have smaller windows
4. **GPS accuracy**: Dependent on source data quality
