# Version 6.7 - Railway Journey Viewer

## 🎉 Major Updates

### 1. **Redesigned Layout**
- **Desktop (>1024px)**: Side-by-side layout with 360° viewer on left, GPS track map on right
- **Mobile (<1024px)**: Stacked vertical layout for optimal viewing
- **Modern Dark Theme**: Beautiful gradient background with improved contrast

### 2. **Journey Statistics Dashboard**
Automatically calculates and displays:
- ✅ **Total Distance** traveled (km)
- ✅ **Duration** (hours and minutes)
- ✅ **Elevation Gain** (meters) - when available
- ✅ **Elevation Loss** (meters) - when available
- ✅ **Average Speed** (km/h) - when time data available
- ✅ **Max Speed** (km/h) - when time data available

### 3. **Interactive Charts**
- 📈 **Elevation Profile Chart**: Shows terrain changes over distance (requires elevation in markers.txt)
- ⚡ **Speed Profile Chart**: Displays speed variations over distance (requires time in markers.txt)
- Both charts use Chart.js with interactive tooltips and smooth animations

### 4. **Enhanced Position Display**
- Prominent card showing: Current frame number, filename, and GPS coordinates
- Real-time updates as you navigate through images
- Clean, readable design with monospace coordinates

### 5. **Additional Statistics Panel**
Shows when available:
- GPS Points count
- Data Source (markers.txt or EXIF)
- Min/Max Elevation
- Start/End Times

### 6. **Smart Data Loading** (from v6.6)
- **Priority 1**: Loads from `markers.txt` (fast, ~100KB for 1600 images)
- **Priority 2**: Falls back to EXIF reading if markers.txt not found (slow, downloads all images)
- Supports elevation and time data from markers.txt

## 📊 markers.txt Format

```csv
image_file,lat,lon,ele,time
frame_00000000.jpg,42.6670102224114,-72.5282775556126,120.078737647273,2024-08-15 13:07:57
frame_00000001.jpg,42.6670117663643,-72.5283123016618,119.617431789637,2024-08-15 13:07:58
...
```

**Columns:**
1. `image_file` - Filename (required)
2. `lat` - Latitude in decimal degrees (required)
3. `lon` - Longitude in decimal degrees (required)
4. `ele` - Elevation in meters (optional, enables elevation charts)
5. `time` - Timestamp in format YYYY-MM-DD HH:MM:SS (optional, enables speed charts)

## 🚀 Performance

### With markers.txt:
- Initial load: ~30-60MB (just metadata + first 15 images)
- Load time: 2-5 seconds
- Cost on AWS S3: ~$0.001-0.01 per user

### Without markers.txt (EXIF fallback):
- Initial load: ~3-6GB (downloads all images for EXIF)
- Load time: 30-120 seconds
- Cost on AWS S3: ~$0.30-0.50 per user

**Recommendation**: Always create markers.txt files for production!

## 🔧 Technical Details

- Added Chart.js 4.4.0 for elevation and speed charts
- Journey statistics calculated using Haversine formula for distance
- Elevation gain/loss calculated from sequential elevation differences
- Speed calculated from distance and time delta between GPS points
- All calculations handle missing/null data gracefully

## 🎯 Best Practices for AWS S3 Hosting

1. Create markers.txt for each dataset
2. Enable CloudFront CDN for faster global delivery
3. Set appropriate cache headers (1 year for images, 1 hour for HTML)
4. Consider using S3 Transfer Acceleration for large datasets
5. Monitor data transfer costs with CloudWatch
